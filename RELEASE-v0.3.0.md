ReviveOS Hybrid Extreme 0.3.0 acrescenta ajustes de sistema efetivos: inicialização de aplicativos opcionais por usuário, SysMain e Windows Search individualmente e paginação gerenciada via CIM. Há simulação/plano, snapshots, validação, reversão individual/completa e preflight de administrador.

O plano só sugere SysMain com HDD detectado e fila elevada em três amostras; não atribui causa sem teste. Windows Search não é selecionado automaticamente. Leia os riscos: ajustes podem piorar abertura de aplicativos, busca ou sincronização. Paginação precisa de reboot; não apaga arquivos pessoais e não promete aceleração impossível.

Nuvem: pesquisa documentada escolhe OCI Always Free A1 como candidato Linux ARM para tarefas SSH; template Terraform incluído. Nenhum recurso foi provisionado. Exige conta, identidade, cota e disponibilidade, sem ativar serviços pagos automaticamente. Não executa AutoCAD Windows nativamente e não fornece estação Windows/GPU gratuita.

Workflow Windows executa testes, diagnóstico, janela WPF, instalação e desinstalação. O teste de inicialização verifica roundtrip de comando e tipo de registro. Serviços/paginação têm leitura testada; alterações administrativas completas e efeitos no notebook ainda pendem de testes reais. Nenhum ganho medido é alegado.
