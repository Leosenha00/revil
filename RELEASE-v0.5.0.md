ReviveOS Hybrid Extreme 0.5.0 acrescenta a CENTRAL HÍBRIDA para escolher motores por tarefa e privacidade: AutoCAD local/Web, Binder, SageMathCell, Python/SymPy, FFmpeg/Blender instalados e host SSH/RDP próprio.

O usuário autorizou usar seu login Autodesk existente. O acesso Web continua dependendo de assinatura compatível, sem consulta de licença por API ou contratação automática. SageMathCell foi testado com uma fatoração real sem login. Binder mantém seu uso interativo temporário, com dados não confidenciais. A central não envia arquivos automaticamente, não usa serviços públicos para renderização pesada e não inventa um host Windows.

Inclui botão para proteger resultados já baixados com o VersionStore local, exemplo matemático e filtros de arquivos coerentes com o adaptador escolhido. A seleção não presume motor mais rápido sem medição.

Veja docs/REQUIREMENT-COVERAGE.md para todos os requisitos implementados, condicionais e pendentes. Wi-Fi físico, ganho no notebook, desenho/licença AutoCAD Web e infraestrutura Windows/GPU real ainda precisam de validação. Não é possível declarar que a soma desses serviços resolve todas as exigências.
